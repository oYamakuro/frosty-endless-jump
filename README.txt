FROSTY – Endless Ice Jump (2.5D Browser Prototype)
Upload index.html to the root of your GitHub Pages repository.
Upload assets/front.png and assets/back.png into the assets/ folder.
Enable GitHub Pages from main / (root).
Controls: touch or tilt, auto or manual jump in settings. Desktop: arrow keys and space.
This is a playable 2.5D prototype using canvas, not a fully modeled 3D scene.
